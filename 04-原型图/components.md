# 组件规范（NEW-059）

所有类名与 `design/mock.css` 一致，实现阶段（Vue + Element Plus）按此 1:1 复刻。

## 1. 按钮 `.btn`

| 变体 | 类名 | 底色 / 文字 | 用途 |
|---|---|---|---|
| 主 | `.btn.p` | `#1D5B63` / `#fff` | 页面唯一主操作（查询、保存、确认预约） |
| 次 | `.btn` | `#fff` / `#1F2933`，描边 `#E3E7E9` | 重置、取消、导出 |
| 描边 | `.btn.o` | 白底 / `#1D5B63`，描边主色 | 次级强调（代签、上传） |
| 强调 | `.btn.a` | `#C97B2E` / `#fff` | 限时操作（候补确认） |
| 危险 | `.btn.d` | 白底 / `#B02A37`，描边 `#E5BEC2` | 删除、清座、撤销违约 |
| 文字 | `.btn.lk` | 无底无边，主色文字 | 表格行内操作 |

尺寸：默认高 30px / 内边距 0 12px / 字号 13px / 圆角 5px；`.btn.sm` 高 26px / 字号 12px。
禁用态 `opacity:.45`，不改变尺寸。按钮不换行（`white-space:nowrap`）。

## 2. 输入 / 选择

- `.inp`：高 30px，圆角 5px，描边 `#E3E7E9`；聚焦 `border-color:#3F8A93` + 3px 外发光 `rgba(63,138,147,.12)`。
- `.sel`：最小宽 180px、最大 240px，右侧 10px 箭头图标（内联 SVG，不依赖图标字体）。
- `.fi`：标签 + 控件的横排包裹，标签 12.5px `#5B6770`，与控件间距 6px。
- 筛选区 `.filters`：flex wrap，间距 10px；右侧放「查询 / 重置」。
- 表单 `.form`：`grid-template-columns:120px 1fr`，必填标签前加红色 `*`，行距 12px。
- 文本域高度 ≥64px，内边距 6/9px。

## 3. 表格 `.tb`

- 表头：底 `#FAFBFB`、字 12px/600 `#5B6770`、高 36px（padding 9/12）、下边框 `#E3E7E9`。
- 单元格：padding 9/12，字号 13px，行分隔 `#F0F2F3`，hover 行底 `#FBFCFC`。
- 表头不固定宽度，按内容自适应；数字列加 `.num`（tabular-nums）。
- 状态列使用 `.tag`，不使用纯色圆点。
- 操作列 `.acts`：flex + gap 2px，最多 3 个文字按钮。

## 4. 标签 `.tag`

高 18px，字号 11.5px，内边距 1/7px，圆角 4px。变体：`b`（主色浅底）、`g`（成功）、`a`（强调）、
`r`（危险）、`o`（信息蓝）、默认（中性灰）。可选前置 5px 圆点 `.d`。

## 5. 卡片 `.card`

白底 + 1px `#E3E7E9` + 8px 圆角 + 双层轻阴影。
- 卡头 `.hd`：高 36px（padding 9/14），标题 13.5px/600，右侧放操作或说明。
- 卡体 `.bd`：padding 12px；`.bd.np` 无内边距（表格、列表直接贴边）。
- KPI `.kpi`：左侧 3px 色条区分语义（主色/强调/成功/危险/辅助），标签 11.5px，数值 20px/700。

## 6. 分页 `.pager`

左「共 N 条」，右页码按钮（26×26，圆角 4，当前页主色底白字）+ 每页条数下拉（88px）。
后端分页，前端保留 page / size。

## 7. 抽屉 `.drawer`

右侧 480px，遮罩 `rgba(15,35,40,.32)`；头部 54px（标题 + 状态标签 + 关闭），
体部滚动，底部固定操作区右对齐。用于审批、流转、清座、申诉、人工修正。

## 8. 座位网格 `.seat`

34×30px、圆角 5px、字号 10.5px，显示座位序号。状态：可约 `#E9F2F1/#2F6F63`、
已约 `#DCE7F0/#3C6382`、使用中 `#1D5B63/#fff`、维修 `#F3E9DC/#A9713A`、停用 `#F0F1F2/#A8B0B4`；
「我的座位」加 2px `#C97B2E` outline。网格 `gap:7px`，每区上方有「讲台 / 出入口」条，
区域之间用 `.divider` 分隔；容器 `.seatwrap` 最大高 392px 内部滚动，保证底部预约条常驻。

## 9. 热力格 `.heat`

`border-spacing:3px`，格高 23px，圆角 4px，白字（浅档改为深字）。6 档：`h1…h6`。

## 10. 时间轴 `.tl`

左侧 1px 竖线 + 7px 圆点；普通点描边 `#3F8A93`，成功 `#2B7955`，异常 `#B02A37`。
每条含时间（11.5px `#8A959C`）与描述（12.5px 正文）。

## 11. 分段器 `.seg`

外框 1px，内部 `a` 以 1px 分隔，选中项主色底白字。用于时间范围、时段切换。

## 12. 提示条 `.alert`

圆角 6px，padding 9/12，字号 12.5px。默认主色浅底（信息），`.a` 强调（建议/待办），`.r` 危险（超时/违约）。

## 13. 门户卡片 `.pcard`

学生端预约卡片：白底 8px 圆角，内含预约码（等宽字体、主色）、状态标签、座位/时段两行、
底部虚线分隔的操作区。「临近开始」加 `.hot`（暖色描边 + 浅暖渐变），倒计时用 `.countdown`（强调色底）。

## 14. 数字键盘 `.keypad` + `.pinbox`

3 列网格，键高 52px、字号 19px/600；输入框 48×56px，当前位 3px 主色外发光；
用于签到页输入预约码后 4 位。

## 15. 图标 `icons.svg`

单文件 SVG symbol 雪碧图，`viewBox 0 0 24 24`，`fill:none`、`stroke:currentColor`、`stroke-width:1.7`、
圆头圆角。共 19 个：dashboard、room、seat、booking、checkin、violation、blacklist、heat、report、rule、
user、role、menu、dict、log、notice、msg、profile、waitlist、college。
侧栏与顶栏图标统一 15–16px，不得使用图片图标。
