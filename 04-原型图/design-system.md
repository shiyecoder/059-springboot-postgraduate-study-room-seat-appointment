# 设计系统 · 静研自习室座位预约系统（NEW-059）

## 1. 视觉定位

冷静专注。深青主色 + 浅灰背景，信息密度偏高但边界清晰；座位图用网格色块表达状态，热力图用单色梯度，
不使用大面积高饱和色。状态一律「颜色 + 中文标签」双通道表达，避免只靠颜色。

## 3. 字体阶梯

| 层级 | 字号 / 字重 | 用途 |
|---|---|---|
| 页面标题 | 18px / 600 | `.ph h1` |
| 卡片标题 | 13.5px / 600 | `.card > .hd h3` |
| 关键数字 | 20px / 700 | `.kpi .vl`，`font-variant-numeric: tabular-nums` |
| 正文 | 14px / 400 | body 默认 |
| 表格 | 13px / 400，表头 12px / 600 | `.tb` |
| 辅助 | 11.5–12.5px / 400 | 说明、时间、次要字段 |

字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`；编号/预约码/代码用
`ui-monospace, Menlo, monospace`，并统一 tabular-nums。

## 4. 间距、圆角、阴影

- 间距基数 4px；卡片内边距 12px，页头下间距 10px，栅格间距 10–12px。
- 圆角：卡片 8px，按钮/输入 5px，标签 4px，座位 5px，头像全圆。
- 阴影：`0 1px 2px rgba(31,41,51,.06), 0 2px 8px rgba(31,41,51,.04)`；抽屉 `-8px 0 28px rgba(31,41,51,.14)`。
- 内容区外边距 16/22/12，侧栏 220px，顶栏 56px。

## 5. 布局规则

- 管理端：220px 固定侧栏 + 56px 顶栏 + 自适应内容区（`.app{height:100vh}`，仅 `.content` 滚动）。
- 学生端：62px 顶部导航（门户风格，无侧栏），内容最大宽 1180px 居中。
- 看板一屏：1440×900 下 `.content` 的 `scrollHeight` 必须等于 `clientHeight`（实测 757/757），
  8 个 KPI 单行 + 6 个图表三行，图表高度 88–116px。
- 栅格：`.g2 / .g3 / .g4 / .g21(2:1) / .g12 / .g6`，图表区默认 2:1。

## 7. 图表规范（不引第三方库，纯 CSS/SVG 实现）

- 折线：`viewBox 0 0 100 40` + `preserveAspectRatio="none"` + `vector-effect:non-scaling-stroke`，
  面积填充 `opacity .10`；横轴标签用 HTML 均分，避免 SVG 拉伸文字。
- 柱状：`.chart` 固定高度 + `.col > i` 百分比高度，柱顶 3px 圆角，强调柱用 `--acc`。
- 环形：`conic-gradient` + 内圈白圆遮罩 + 中心数字。
- 横向条：`.hbar` 名称固定 96px、轨道自适应、数值右对齐。
- 热力：6 档单色梯度（`#E3ECEC → #A9C8C6 → #6FA3A0 → #3F8A93 → #1D5B63 → #8C3A2E`），
  格子内直接显示百分比，右侧必须有图例。
- 所有图表点击可跳转到带筛选条件的列表（实现阶段用路由 query 传递）。

## 8. 交互约定

- 表格行内最多「查看 + 2 个高频操作」，其余收进更多菜单；危险操作红色描边 + 二次确认。
- 审批、流转、清座、申诉统一用右侧抽屉（480px），抽屉内保留单据摘要。
- 加载超过 300ms 显示局部骨架；空状态说明原因与下一步。
- 表单标签 100–120px，单列输入 360–520px，搜索下拉 180–240px。
